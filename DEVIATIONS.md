# Deviations from the authors' replication procedure

Every place where this replication departs from the authors' archive or README.
The authors' code files are used byte-identical (`diff -rq -x __pycache__` of
archive/code and work/code shows no difference; the archive copy was once imported
in place, so both directories also hold Python bytecode caches, which differ). Departures are in the environment, file names,
and thin wrapper scripts in `scripts/` that call the authors' functions; no
change to experimental logic.

Archive: Harvard Dataverse doi:10.7910/DVN/NUWHQP, **version 1.2** (released
2026-03-14), pinned in `scripts/download_archive.py`.
